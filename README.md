# blip-chocolatey
a chocolatey package for blip.net - 
this repo doesn't includes the software, just packages it for chocolatey for users to be able to use Chocolatey to get Blip via the package manager.
The logo had to be copied into the repo because Blip.net only provides the SVG code instead of the file.
I classify this as fair use, because it's solely meant to distribute the official microsoft store installation method to package managers. 

This package uses winget to install from their official Microsoft Store source. It just automates the process so it can be packaged into a chocolatey package
